## About this guide

AWS Machine Learning Blog post by Markus Adhiwiyogo (AWS), published November 11, 2026. re:Invent 2026 runs November 30 to December 4 with more than 2,000 sessions; the AI/ML track has more than 140.

## Session formats and lengths

- Breakouts: 60-minute talks, recorded and posted to the AWS Events YouTube channel.
- Chalk talks: whiteboard discussions.
- Builder sessions: one hour, building something hands-on.
- Workshops: two hours, small teams working a real problem.
- Code talks: expert-led live coding.
- Lightning talks: 20-minute demos in the Venetian Expo Hall or the Wynn/Encore Upper Convention Promenade.

## Good starting sessions

- AIM204: overview of the full AWS AI stack.
- AIM364: choosing between Amazon Bedrock and Amazon SageMaker AI.
- AIM220: introduction to Amazon Bedrock and AgentCore; AIM317: Bedrock workshop.
- AIM342: introduction to SageMaker AI.
- AIM211: where to start with AWS Trainium; AIM310: Trainium3.
- AIM363: data for AI; AIM319: AI ROI.
- AIM407: Strands Agents; AIM408: managed MLflow.
- Responsible AI: AIM2216 (panel), AIM391 (John Deere).
- Sustainability: AIM201, AIM205.

The track is organized from infrastructure and chips (Trainium, NVIDIA GPUs) through data, models (Bedrock, SageMaker AI), agents (Bedrock AgentCore) and ready-made agentic products, with beginner sessions listed before advanced ones.

## AWS Village in the Venetian Expo Hall

- AI kiosks staffed by AWS experts, covering Bedrock, AgentCore, Amazon foundation models, speech AI, accelerated computing, Strands Agents, AI League, SageMaker AI, global infrastructure and sustainability, and hybrid cloud and edge.
- Interactive activations: AWS Quick, Galactic Agents (a builder game), Security at Machine Speed (a tabletop game) and an AWS Cloud Infrastructure hardware display.
- The Builder's Hub runs contests such as fine-tuning an agent, the Agentic Football Cup and teaching a robot a task.

## Planning tips from the post

- Reserve seats early in the event catalog; popular sessions fill quickly.
- If a session is full, favorite it and try at the door, since seats sometimes open up.
- Use the kiosks and activations between sessions.
- Keynotes stream live and breakouts can be watched later on YouTube.
