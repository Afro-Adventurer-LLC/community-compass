## Using AWS Builder ID to register

### What is AWS Builder ID and AWS Profile?

AWS Builder ID is a simple, personal identity for users, providing access to select AWS tools and services. This year, you'll be able to create or use an existing Builder ID to register for AWS re:Invent 2026. With AWS Builder ID, you can create an AWS Profile: a central place to manage your personal information and preferences. Your AWS Profile information is applied consistently across supported AWS experiences.

### Is Builder ID authentication required to register for AWS re:Invent?

Yes. AWS Builder ID is required to register for re:Invent. The Builder ID serves as the authentication method for your re:Invent account.

### How do I register for re:Invent using Builder ID?

Enter your email (business email preferred) or select one of the other authentication methods. If this is your first time setting up a Builder ID, you'll be prompted to create a password that you'll use to log into your re:Invent account, as well as your AWS Builder ID account. If you already have a Builder ID account, enter the credentials you normally use or select reset password.

### Who can I contact with additional questions?

Please email awsreinvent-support@amazon.com for support.

### What if I already have an AWS Builder ID account?

If you already have an AWS Builder ID profile, you can use those same credentials to log into your re:Invent account.

### Can I delete my Builder ID account after the event?

If you no longer want to have your AWS Builder ID account, you can delete it post-event by following the instructions found in the Builder ID overview. Please note that if you delete your Builder ID account, you will also lose access to your current re:Invent account.
